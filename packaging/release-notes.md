## Install

1. Download **Soundboard-Setup.exe** (or the zip, which also contains English and French readme files).
2. If **Smart App Control** is on, turn it off: *Windows Security → App & browser control → Smart App Control settings → Off*. Soundboard is not code-signed.
3. Run the installer. If SmartScreen appears, click **More info → Run anyway**.
4. On first launch, tick your microphone and click **Apply**.
5. In Discord, set *Noise Suppression* to **None**.

Already installed? Run the new installer: it updates Soundboard in place and keeps your sounds and settings.

Windows 10/11, 64-bit. The app is in English and French (it follows the Windows language; see Settings → General → Language).
